# obsidian-html

Obsidianノートを、リンクをたどりながら収集して1つのHTMLに出力するプラグイン／CLIツールです。

## Obsidianプラグインとして使う

デスクトップ版Obsidian 1.5.0以上に対応しています。プラグイン実行時はNode.jsの別途インストール、Obsidian CLI、他の拡張機能は不要です。

1. このフォルダーで `npm install` → `npm run build` を実行します（ビルド時のみNode.js 18以上が必要）。
2. 生成された `plugin/obsidian-html` フォルダーを、Vaultの `.obsidian/plugins/obsidian-html` にコピーします。`templates` フォルダーも含めてコピーしてください。設定フォルダー名を変更している場合はその場所を使ってください。
3. Obsidianを再起動し、「設定 → コミュニティプラグイン」で **Obsidian HTML** を有効にします。まだコミュニティ一覧には公開されていないため、手動インストールです。
4. Markdownノートを開き、コマンドパレットで **Obsidian HTML: 現在のノートをHTMLに出力（深度を指定）** を実行します。左リボンのボタンやファイルの右クリックメニューからも実行できます。
5. 開いた画面でリンクの深さと保存先を指定し、「HTMLを出力」を押します。深さ0は起点だけ、1は直接リンクしたノート、2はさらにそのリンク先までです。ノートへの埋め込みとプロパティ内のリンクも収集対象です。

「設定 → Obsidian HTML」で既定の深度、出力フォルダー、ライト／ダークテーマ、カスタムCSSを保存できます。保存先とCSSのパスはVaultからの相対パス、または絶対パスです。既定の保存先は `HTML Exports/ノート名.html` です。ノート名に日付などを追加しません。同名のHTMLがある場合は、確認なしで常に上書きします。

**ショートカット**: 「設定 → ホットキー」で `Obsidian HTML` を検索して上記コマンドに割り当てます。

更新時も `npm run build` 後に生成フォルダーをコピーし直して、プラグインを再読み込みしてください。実行時のノート本文はVault APIから取得するため、編集中のノートは保存してから実行してください。

以下は従来のCLIの利用方法です。CLI実行時にはObsidian CLIの有効化が必要です。

## 特徴

- **単一HTML出力**: CSS、シンタックスハイライト、Vault内の画像を埋め込んだ1つのHTMLファイルを出力します。MathJax・MermaidはCDNから読み込むため、数式・図の表示にはインターネット接続が必要です。外部URLの画像も取得・埋め込みは行いません。
- **本家Obsidian仕様の完全再現**:
  - **テーマデザイン**: 紫ベースの独自の装飾を廃止し、本家Obsidian公式のデフォルトテーマカラー（ライト/ダーク）とフラットな面取りのない（角丸なし）シンプルなデザインを忠実に再現。
  - **コールアウト**: 本家と同一の配色、透過的な背景、左側の太いボーダー、折りたたみ対応（`> [!note]+` / `> [!note]-`）、公式Lucide SVGアイコンを完備。
  - **数式（LaTeX）**: 本家と同じ **MathJax** レンダラーを導入。数式の崩れや文字詰まりを解消し、公式表示と完全に同一の高品質なフォント・数式レイアウトで描画します。
  - **タスクリスト**: `- [ ]` や `- [x]` を本家風のチェックボックスに自動変換。チェック済みタスクの打消し線と文字色薄化も再現。
  - **画像のサイズ指定**: `![[image.png|300]]`（横幅のみ）や `![[image.png|300x200]]`（縦横両方）のようなサイズ指定に対応。
  - **脚注（Footnote）**: `[^1]` や `[^1]: 本文` の脚注アンカーおよび最下部の脚注リストの構築をフルサポート。
  - **コメントアウト自動除去**: Obsidian形式の `%% コメント %%` や HTML形式の `<!-- コメント -->` は出力HTMLから完全に自動除去します。
- **パンくずリスト（Breadcrumbs）**: 各ノートのヘッダーに起点からの遷移パスを表示。パンくず内のノート名をクリックして相互にジャンプ・スクロール可能です。
- **Mermaid対応**: フローチャートやグラフ（` ```mermaid `）の動的描画に対応。
- **サイドバー追跡**: スクロール位置と連動してサイドバー内のアクティブノートが自動追跡されてハイライトされます。

## 必要環境

- **Node.js** 18.0.0 以上
- **Obsidian 1.12.7+** がインストール・起動済みで、CLIが有効化されていること
  - `設定 → 一般 → コマンドラインインターフェース` を有効化

## インストール

```bash
cd obsidian-html
npm install
npm run build
```

コマンドとしてシステムに登録（グローバルインストール）する場合：

```bash
npm install -g .
```

## 使い方

```bash
# 基本的な使い方（"サンプルノート" から深さ2までのノートを収集）
obsidian-html build --note "サンプルノート" --depth 2 --output ./output.html

# ライトテーマで出力
obsidian-html build --note "サンプルノート" --theme light

# 特定のVaultを指定
obsidian-html build --note "サンプルノート" --vault "My Vault"

# 起点ノートのみ（深さ0）
obsidian-html build --note "サンプルノート" --depth 0

# カスタムCSSをビルド時に直接適用（再ビルド不要で iterative なデザイン調整が可能）
obsidian-html build --note "サンプルノート" --css "./custom.css"
```

## オプション一覧

| オプション | 短縮形 | 説明 | デフォルト |
|-----------|--------|------|-----------|
| `--note <name>` | `-n` | 収集を開始する起点ノート名（必須） | — |
| `--depth <n>` | `-d` | リンクをたどる最大の深さ (0 = 起点のみ) | `2` |
| `--output <path>` | `-o` | 出力HTMLファイルの保存パス | `./output.html` |
| `--vault <name>` | `-v` | 使用するVaultの名前 | CWDまたは起動中のVault |
| `--theme <dark\|light>` | — | カラーテーマ | `dark` |
| `--css <path>` | — | 適用するカスタムCSSの絶対/相対パス | プリセットのCSSを使用 |

## 出力HTMLの構造

- **サイドバー**: 収集されたノート一覧。クリックで該当箇所にスクロール。
- **メインコンテンツ**: 起点から近いノート順に、フラットなカード形式で表示。
- **アクティブ追跡**: スクロールに応じて、読んでいるノートのサイドバーリンクが自動ハイライト。
- **パンくず**: 各ノートのヘッダーにパスを表示。リンクになっており他のノートへジャンプ可能。

## カスタマイズ

`src/templates/style.css` を編集し、以下のビルドを実行すると独自のテーマを焼き込めます。

```bash
npm run build
```

もしくは、ビルド時に `--css <ファイルパス>` オプションを使用することで、ビルド済みのCSSを使わずに直接指定したCSSでHTMLを構築できます。

## トラブルシューティング

**`Obsidian CLI エラー` と表示される場合**
1. Obsidian アプリが起動しているか確認してください。
2. `設定 → 一般 → コマンドラインインターフェース` がオンになっているか確認してください。
3. ターミナルで `obsidian version` コマンドが正しく返ってくるか確認してください。

**画像が表示されない場合**
- `--vault <name>` を使って使用しているVaultの名前を明示的に指定してください。
- 画像がVault内の標準的なディレクトリ（`Attachments/`, `Assets/`, `Images/` など）に入っているか確認してください。
